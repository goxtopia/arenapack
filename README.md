# LATENT EPOCH · 潜在纪元

**语言模型进化实证观测站 — 2025.01.20 → 2026.11.03（652 天）**

一个可交互的单页应用，用十个模块呈现 2025 年初至今语言模型的演化。立场是客观、诚实、公正：既记录突破，也记录失信、饱和、幻觉与账单膨胀。

## 核心原则

页面上的**每一个数字都标注来源**：

- `[厂商公布]` — 来自发布方自己的技术报告或发布材料
- `[独立实测]` — 来自 METR / LMArena / 学术复现等第三方

不同 harness（含工具 vs 纯文本、SWE-bench Verified vs Pro、beta 上下文）的数字**不作横向比较**，harness 差异逐条注明。

## 十个模块

| # | 模块 | 内容 |
|---|---|---|
| 01 | **星图观测台** | 2.5D Canvas 谱系星图。横轴时间，纵轴可切换 8 种叙事（SWE-V / ARC-AGI-2 / HLE / METR / 单价倒数 / 上下文 / 参数量 / 纯谱系）。影院模式自动播放、时间播放头、血缘连线、实验室与许可筛选。 |
| 02 | **五幕编年** | Scrollytelling。每幕含「发生了什么」+「这一幕最容易被讲错的地方」。 |
| 03 | **基准博物馆** | 12 具基准标本，按 `已饱和 / 已退役 / 受质疑 / 仍有效` 分类陈列。 |
| 04 | **自主任务时长曲线** | METR Time Horizon。对数/线性刻度切换、双区间指数拟合、>16h 不可靠区间标注、可选的「未来外推」演示。 |
| 05 | **智能价格战** | 能力–价格 Pareto 散点 + 时间截面滑杆 + 智能价格指数阶梯 + Token 账单模拟器（含 2025 初反事实对照，演示 Jevons 悖论）。 |
| 06 | **开源 / 闭源** | 按许可堆叠的累计发布面积图 + 最大可下载权重规模阶梯 + 本地部署现实检查器（显存估算 → 最低成本 GPU 配置）。 |
| 07 | **祛魅账本** | 6 条系统性核查，每条结构为：流行说法 → 证据 → **反向权重** → 结论。 |
| 08 | **跨代对决** | 任意两条目并排逐项比较，含 6 组预设对照。缺失数据不计入胜负。 |
| 09 | **全量年表** | 111 条记录，可搜索、可排序、可按实验室/许可筛选。 |
| 10 | **引用与方法** | 22 项来源、方法论、以及**本页面的已知局限**。 |

## 数据

`src/data/` 下全部为手工汇编并交叉核对的结构化数据：

- `models.ts` — 111 条发布事件（含 1 项从未发布、5 项受限发放档位、1 项行业结构事件；其中 31 条为 MIT / Apache-2.0，38 条权重可下载）
- `acts.ts` — 五幕叙事
- `benchmarks.ts` — 12 条基准时间序列
- `metr.ts` — METR 任务时长数据点（含 2019–2024 回溯锚点，明确标注）
- `critiques.ts` — 6 条核查
- `sources.ts` — 22 项来源
- `labs.ts` — 11 家实验室立场

价格 = 发布时官方 API 列表价（$/1M tokens），不含批量折扣、prompt 缓存命中折扣、预置容量与订阅折算。

## 技术栈

Vite 6 · React 19 · TypeScript · Tailwind CSS 3 · lucide-react · 原生 Canvas 2D / SVG（无图表库）

## 开发

```bash
npm install
npm run dev      # http://0.0.0.0:5173
npm run build    # tsc --noEmit && vite build
```
